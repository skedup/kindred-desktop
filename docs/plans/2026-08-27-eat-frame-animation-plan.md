# `eat` 坐姿帧动画实施计划

状态：实施中（EAT-4 本机视觉验收已通过，等待定向 review）
日期：2026-08-27
设计依据：[eat 坐姿帧动画设计](../discussions/2026-08-27-eat-frame-animation-design.md)

## Goal

用 `draw` 的固定道具层、连续人物表面、刚性小道具和可验证发布链，替换当前站姿且机械的 `eat` FRAME1，交付一段 84 帧、12 FPS、7 秒的坐姿进食闭环。

## 范围控制

本 Goal 只交付 `eat` 资源和对应生产工具。它不修改 action 协议、renderer、远端数据源，不同时重做其他动作，也不增加兼容层或保障式双路径。

## 阶段与任务

### EAT-0：设计闸门

- [x] 确认采用早餐桌前的中近景构图，而不是全身旁置边桌。
- [x] 确认近似正交、轻微俯视、接近正面的三分之四透视关系。
- [x] 确认最小道具组合：椅子、早餐桌、碗、勺和小面包盘。
- [x] 确认“后景静态层 → 连续人物层 → 刚性勺子层 → 前景遮挡层”的合成顺序。
- [x] 确认 84 帧 / 12 FPS / 7 秒时间线。
- [x] 确认 action 语义目录 `eat-v2`，不延续跨 action 的 FRAME 编号。

完成条件：设计文档无未决的构图或技术分层问题。

- [x] 分离后景静态层：椅背、桌面、碗后部和小面包盘。
- [x] 分离从头部到下躯干的连续人物表面，并从母版中提取刚性勺子层。
- [x] 分离前景遮挡层：桌沿、碗前部和必要的餐盘前沿。
- [x] 分别生成后景与前景静态区域的可见语义 mask。

完成条件：人物身份、材质、两只手和道具关系通过母版闸门；所有分层可无缝重组为获准母版。

### EAT-4：运行时验收

- [x] 在 macOS 桌面应用中连续循环至少 10 次。
- [x] 在当前固定 320×540 shell 中检查动作可读性；窗口不可缩放，因此不存在独立的最小缩放档。
- [x] 检查透明窗口边缘、常驻最前端和 reduced-motion 模式。
- [x] 确认 action 从 `eat` 切换到其他状态、再切回时无闪烁或错误残帧。
- [ ] 完成一次定向代码/资源 review。

本机验收记录：连续播放超过 70 秒，稳定阶段 CPU 约 3.3%–3.7%，内存约
23–31 MiB；`eat → settle → eat` 切换未出现空白帧或错误残帧；开启 macOS
“减弱动态效果”后，两次间隔采样均固定为获准首帧，恢复设置后正常播放。
验收结束后已将应用观察来源恢复为 `Local`，并关闭临时 mock 服务。

完成条件：本机视觉验收通过，review 无阻塞问题。

## 实施顺序

```text
设计确认
  → 母版生成与人工批准
  → 道具/人物/勺子分层
  → 确定性 84 帧生成
  → 动画人工批准
  → 自动验证与事务性 promotion
  → macOS 运行时验收
  → review 与合入
```

## Definition of Done

- `eat` 明确表现为早餐桌前自然进食，不再是站立机械抬手；
- 椅子、桌面、碗、小面包盘和前景桌沿全循环固定；
- 人物动作包括肩、肘、腕、头、眼神、上身与扶碗手联动；
- 人物无接缝、残影、身份漂移和材质闪烁；
- 勺子不形变、不穿插，并与手保持稳定接触；
- 84 帧以 12 FPS 平滑闭环；
- source、批准记录和 runtime 资源可追溯且哈希一致；
- 当前运行时只保留新的 `eat-v2` 路径。

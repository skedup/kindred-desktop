# Contributing

Use a focused pull request for each runtime, renderer, visual-pack, or production-tool change.
When an action changes, keep its approved source, runtime frames, motion manifest, validation, and
renderer compatibility in the same pull request.

Before submitting, run the commands in the README. Do not commit `node_modules`, Rust `target`,
Vite output, preview media, rejected image-generation candidates, resident data, or credentials.
